وب‌سایت فراخوان هفته پژوهش ۱۴۰۵ — نسخه بازطراحی‌شده

ساختار فایل‌ها
- index.html: صفحه اصلی (معرفی، دو فراخوان با پوستر، گام‌های ارسال، ضوابط، تماس)
- article-guide.html: راهنمای ارسال مقالات و پایان‌نامه‌ها
- book-guide.html: راهنمای معرفی کتاب و دست‌نوشته
- 404.html: صفحه «پیدا نشد»
- css/style.css: استایل کل سایت
- js/main.js: شمارش معکوس مهلت، نمایش بزرگ پوستر، دکمه‌های کپی و اشتراک‌گذاری
- assets/: پوسترها (نسخه کامل و نسخه سبک)، آیکون سایت
- .nojekyll: فایل خالی که GitHub Pages به آن نیاز دارد؛ حذفش نکنید (اگر در آپلود دیده نشد، مهم نیست)

روش انتشار روی GitHub Pages
۱. در مخزن، همه فایل‌ها و پوشه‌های قدیمی را حذف کنید (یا روی آن‌ها بنویسید).
۲. محتویات همین پوشه را (نه خود پوشه را) آپلود کنید: Add file ← Upload files.
   index.html باید مستقیماً در ریشه مخزن باشد و پوشه‌های css و js و assets کنار آن.
۳. Commit بزنید و ۱ تا ۲ دقیقه صبر کنید. بعد با Ctrl+F5 صفحه را رفرش کنید.

اگر استایل نیامد (صفحه بدون رنگ و چینش بود)
- آدرس زیر را باز کنید؛ باید متن کد CSS را ببینید:
  https://pooryaminaei96.github.io/kurdistan_research_portal/css/style.css
- اگر ۴۰۴ داد، پوشه css با حروف کوچک ساخته نشده است. GitHub به حروف بزرگ و کوچک حساس است.
- بعد از هر تغییر در CSS یا JS، عدد ?v=2 را در تگ‌های link و script هر سه صفحه یکی بالا ببرید
  (مثلاً ?v=3) تا مرورگرها نسخه قدیمی را نشان ندهند.

تغییر مهلت ارسال
۱. در js/main.js خط DEADLINE را عوض کنید (تاریخ میلادی، پایان روز به وقت ایران).
   ۱۱ آذر ۱۴۰۵ برابر ۲ دسامبر ۲۰۲۶ است.
۲. متن «۱۱ آذرماه ۱۴۰۵» را در سه فایل HTML جایگزین کنید (با جست‌وجو در ویرایشگر).

فونت
